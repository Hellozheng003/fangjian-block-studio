从一块开始，自由搭建。

八种预设颜色和自定义颜色，可以组成大方块，也可以创造任何形状。

  1. 搭建：按 W，选择颜色，点击地面或方块表面。高度 Y 可用来放置悬空方块。
  2. 固定成整体：按 V，Shift + 点击多选方块，按 G 组成一个不可拆改的整体。需要修改形状时，先解散组合；改色无需解散，按 P 后点击想修改的小方块即可。
  3. 拼接：拖动选中的组合，或修改 X / Y / Z 坐标。自动按整数网格吸附，重叠会被阻止。按 T 显示移动箭头，拖动绿箭头可上下移动；按住 Alt 拖动对象也可升降。按 R 显示旋转环，拖动任一彩色圆环旋转；浮动工具条可选择 X/Y/Z 轴并点击 ±90°。
  4. 锁定位置：点击“固定位置”，防止组合被误移动；再次点击可解除。
  5. 观察：右键或在空白处左键拖动旋转，滚轮缩放，中键拖动平移。视角可任意转动，积木旋转保留 90° 网格对齐。
  6. 保存：作品自动保存在当前浏览器；“保存作品”下载 JSON 文件，可导入继续编辑。Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Ctrl+D 复制，Delete 删除。

开源基础：Three.js（MIT）。交互参考 voxel-builder，本网页的搭建和组合逻辑独立实现。
